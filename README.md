## 🚀 1. Запуск веб-приложения

Файл `sulfur-recipesV1.1.html` не требует сборки, серверов или установки зависимостей — вся база предметов, рецептов, эффектов, цен продажи и габаритов ячеек уже встроена внутрь.

### Вариант А — Локальный запуск
1. Скачайте файл `sulfur-recipesV1.1.html`.
2. Откройте его двойным кликом в любом современном браузере (**Chrome**, **Edge**, **Firefox**, **Safari**).

### Вариант Б — прямо в GitHub
1. Перейдите по ссылке `sulfur-recipesV1.1.html`

## 🎨 2. Экспорт иконок из игры (Python)

Скрипт `export_item_icons.py` извлекает оригинальные текстуры предметов напрямую из ресурсов установленной игры **SULFUR** и сохраняет их под внутренними системными именами (`Item_Bread.png`, `Enchantment_Fire.png` и т.д.), которые на 100% совпадают с базой сайта.

### Шаг 1. Установка библиотек
Убедитесь, что у вас установлен **Python 3.8+**, и выполните в терминале:

```bash
pip install UnityPy pillow
```

### Шаг 2. Извлечение ассетов
Запустите скрипт, передав первым аргументом путь к корневой папке игры **SULFUR**, а вторым — имя выходной папки (необязательно, по умолчанию создастся `item_icons`):

```bash
python export_item_icons.py "C:\Program Files (x86)\Steam\steamapps\common\SULFUR" item_icons
```

Пример вывода скрипта в консоли:

```text
Файлов данных: 42
Сохранено иконок: 248; без ссылки на картинку: 0; не удалось: 0 -> item_icons
```

> [!NOTE]
> Скрипт автоматически сканирует файлы `.assets`, `.bundle`, `level*` и `globalgamemanagers`, находит все объекты предметов (`MonoBehaviour` с полями `displayName`, `basePrice`, `artwork`), сохраняет PNG-иконки и генерирует карту соответствий `_map.json`:
> ```json
> {
>  "Item_Bread": "Хлеб",
>  "Item_HealthPotion": "Зелье здоровья",
>  "Enchantment_HolyFire": "Свиток Святого Огня"
> }
> ```

### Шаг 3. Импорт иконок в браузер
1. Откройте `sulfur-recipesV1.1.html` в браузере.
2. На верхней панели управления нажмите кнопку **«Выбрать папку игры»** и укажите папку `item_icons`.
3. Все иконки сохранятся в локальную базу браузера (**IndexedDB**), а переключатель **«Только локальные»** активируется автоматически.

## ✨ Основные возможности веб-приложения

### 📖 Справочник рецептов (<kbd>R</kbd>)
* **Мгновенный поиск (<kbd>/</kbd>):** ищет одновременно по русским и английским названиям предметов.
* **Умные фильтры:** быстрая сортировка на `Все`, `Крафтятся`, `Сырьё`, `Свитки` и `В инвентаре`.
* **Полные цепочки:** при клике на любой предмет отображаются:
  * список всех блюд и предметов, которые можно из него создать;
  * подробная таблица ингредиентов с подсветкой выбранного ресурса;
  * эффекты при употреблении/зачаровании и базовая цена продажи;
  * способы получения самого предмета (если он крафтится).

### 🎒 Мой инвентарь (<kbd>I</kbd>) и Оптимальный крафт (<kbd>O</kbd>)
* **Быстрые слоты (<kbd>1</kbd>–<kbd>9</kbd>):** нижняя панель позволяет закрепить 9 часто используемых предметов для добавления/удаления в один клик.
* **Автосохранение и отмена:** состояние инвентаря и закреплённые слоты хранятся в `localStorage`. Любое действие можно откатить комбинацией <kbd>Ctrl</kbd> + <kbd>Z</kbd> (до 60 шагов).
* **Оптимальный выбор (<kbd>O</kbd>):** встроенный решатель перебирает комбинации рецептов и находит стратегию, дающую **максимальное суммарное количество** готовых предметов из ваших ресурсов. Нажатие <kbd>A</kbd> (**«Применить к инвентарю»**) автоматически списывает ингредиенты и начисляет результат.

## 📸 Распознавание скриншота инвентаря

Веб-приложение умеет определять предметы прямо по скриншоту из игры:

1. Перейдите во вкладку **«Мой инвентарь»** (<kbd>I</kbd>).
2. Загрузите изображение любым удобным способом:
   * перетащите файл в зону загрузки (**Drag & Drop**);
   * вставьте скриншот из буфера обмена нажатием <kbd>Ctrl</kbd> + <kbd>V</kbd>;
   * выберите файл через кнопку **«выберите файл»**.
3. **Настройте сетку:** ползунками **«Ячейка»**, **«Сдвиг X»** и **«Сдвиг Y»** совместите красную разметку с границами ячеек на скриншоте.
4. **Разметьте предметы:**
   * нажмите **«Авторазметка»** для автоматического поиска занятых слотов;
   * или выделите предметы вручную в режиме **«Рамки»** (повторный клик по рамке удаляет её, клик в режиме **«Назвать предмет»** позволяет выбрать предмет из списка вручную).

| Цвет рамки | Размер в сетке | Примеры предметов |
| :---: | :---: | :--- |
| 🟦 Синий | `1×1` | Яйцо, Травы, Зелье здоровья, Соль |
| 🟧 Оранжевый | `2×1` / `1×2` | Хлеб, Свитки, Бутылка воды, Печень |
| 🟪 Фиолетовый | `3×1` | Янссонс-фрестелсе |
| 🟩 Зелёный | `2×2` | Мука, Сахар, Рис, Аптечка, Пицца |
| 🩷 Розовый | `> 4 ячеек` | Простая белая футболка (`2×3`), Жаркое (`3×2`) |

5. **Распознайте:** при необходимости активируйте опцию **«Учитывать повёрнутые предметы»**, отрегулируйте ползунок **«Порог»** и нажмите **«Распознать»**.

> [!IMPORTANT]
> Алгоритм определяет **тип и габариты предмета** по его иконке, но не считывает числовой счётчик стака в углу ячейки. Если у вас в одной ячейке лежит несколько одинаковых предметов, скорректируйте их количество вручную после распознавания.

## ❓ Частые вопросы (FAQ)

<details>
<summary><b>При нажатии «Распознать» появляется ошибка CORS. Что делать?</b></summary>

<br>

Браузер блокирует чтение пикселей картинок, загруженных со сторонних доменов (`sulfur.wiki.gg`), если HTML-страница открыта как локальный файл (`file://`).
* **Решение 1:** извлеките иконки с помощью `export_item_icons.py` и загрузите их через кнопку **«Выбрать папку игры»** — локальные файлы из `IndexedDB` не имеют ограничений CORS.
* **Решение 2:** разместите HTML-файл на **GitHub Pages** или запустите через любой локальный веб-сервер (например, `python -m http.server`).
</details>

<details>
<summary><b>Почему часть иконок не скачалась автоматически с вики?</b></summary>

<br>

На вики некоторые внутренние названия файлов могут отличаться или отсутствовать. Использование скрипта `export_item_icons.py` решает эту проблему полностью, так как выгружает все **100%** иконок напрямую из установленной копии игры.
</details>
