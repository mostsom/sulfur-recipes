# SULFUR — Справочник рецептов, калькулятор инвентаря и экспорт иконок
Набор инструментов для игры SULFUR, включающий автономное однофайловое веб-приложение (sulfur-recipesV1.1.html) для работы с рецептами и инвентарём, а также Python-скрипт (export_item_icons.py) для извлечения оригинальных иконок предметов напрямую из файлов игры.1. Запуск веб-приложения (sulfur-recipesV1.1.html)Веб-приложение полностью автономно: база предметов, рецептов, эффектов, цен продажи и размеров ячеек встроена в один HTML-файл.Локальный запуск: скачайте sulfur-recipesV1.1.html и откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari).Размещение на GitHub Pages: загрузите sulfur-recipesV1.1.html в репозиторий (при необходимости переименовав в index.html) и включите GitHub Pages в настройках репозитория — это также устраняет ограничения браузера (CORS) при работе с иконками.Сохранение данных: состав инвентаря и закреплённые быстрые слоты сохраняются в localStorage браузера, а загруженные иконки кэшируются в IndexedDB.2. Экспорт иконок из игры (export_item_icons.py)Зачем нужен скриптПо умолчанию веб-приложение пытается загружать иконки с sulfur.wiki.gg и sulfur.fandom.com. Однако при запуске страницы как локального файла (file://) браузер может блокировать чтение пикселей иконок политикой CORS (что необходимо для распознавания скриншотов), а часть иконок может отсутствовать на вики. Скрипт export_item_icons.py извлекает текстуры напрямую из ресурсов игры и сохраняет их под внутренними именами (Item_Bread.png и т.д.), которые полностью совпадают с базой сайта.Установка зависимостейУбедитесь, что установлен Python 3, и установите библиотеки UnityPy и pillow:pip install UnityPy pillow
Извлечение иконокЗапустите скрипт, указав путь к корневой папке установленной игры SULFUR и папку для сохранения результатов:python export_item_icons.py "C:\путь\к\папке\SULFUR" item_icons
Второй аргумент (item_icons) необязателен — если его не указывать, папка item_icons создастся в текущей директории по умолчанию.Скрипт автоматически просканирует файлы .assets, .bundle, level* и globalgamemanagers, сохранит PNG-файлы и создаст справочный файл _map.json.Импорт иконок на сайтОткройте sulfur-recipesV1.1.html в браузере.На верхней панели нажмите кнопку «Выбрать папку игры» и укажите созданную папку item_icons.Иконки сохранятся в локальное хранилище браузера (IndexedDB), а опция «Только локальные» включится автоматически.Альтернатива без скрипта: в верхней панели сайта можно нажать «Скачать все иконки» для загрузки изображений с вики или «Загрузить файлы» для ручного добавления отдельных картинок.3. Основные возможности сайтаСправочник (R)Поиск и фильтрация: мгновенный поиск по русским и английским названиям (/), а также фильтры по категориям: «Все», «Крафтятся», «Сырьё», «Свитки» и «В инвентаре».Цепочки крафта: при выборе любого предмета отображается список всех блюд и предметов, которые можно из него сделать, подробная таблица ингредиентов, эффекты предмета и его цена продажи.Мой инвентарь (I) и оптимальный крафт (O)Учёт ресурсов: добавляйте предметы кликом по карточкам в режиме инвентаря или с помощью 9 закрепляемых быстрых слотов внизу экрана.Доступные рецепты: в блоке «Что можно сделать сейчас» отображаются все рецепты, для которых хватает текущих ресурсов, и максимальное количество доступных крафтов.Оптимальный выбор (O): встроенный алгоритм перебирает комбинации рецептов и находит вариант с максимальным итоговым количеством скрафченных предметов. Нажмите «Применить к инвентарю» (A), чтобы автоматически списать ингредиенты и добавить результат в инвентарь.Распознавание скриншота инвентаряПерейдите во вкладку «Мой инвентарь».Перетащите скриншот инвентаря в область загрузки, вставьте его из буфера обмена (Ctrl+V) или выберите файл с диска.Ползунками «Ячейка», «Сдвиг X» и «Сдвиг Y» совместите красную сетку с ячейками инвентаря на скриншоте.Выделите предметы мышью в режиме «Рамки» (поддерживаются размеры 1×1, 2×1, 1×2, 2×2 и др.; повторный клик по рамке удаляет её) или нажмите «Авторазметка». При необходимости уточните конкретный предмет вручную в режиме «Назвать предмет».Настройте «Порог» уверенности, при необходимости оставьте включённой опцию «Учитывать повёрнутые предметы» и нажмите «Распознать». Если включена галочка автоматического добавления, найденные предметы сразу попадут в инвентарь (отмена — Ctrl+Z).4.
